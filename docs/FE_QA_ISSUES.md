### 상태 카테고리 상세 (#50)

**현재 상황:**
- 대시보드: 미제출 / 검토중 / 보완요청 / 완료
- 기안관리: 작성중 / 제출됨 / 승인됨 / 반려됨 / 심사중 / 완료

**BE DiagnosticStatus enum:**
```
WRITING → SUBMITTED → RETURNED/APPROVED → REVIEWING → COMPLETED
```

**요청사항:**
- 백엔드 enum 기준으로 통일
- 각 상태 간 매핑 관계 협의 필요
